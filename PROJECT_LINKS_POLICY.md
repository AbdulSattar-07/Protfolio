## 🎯 Why This Approach?

### ✅ Professional Standards
- Company projects remain confidential
- No fake or placeholder links (#)
- No generic GitHub profile links as project links
- Clear distinction between public and private work

### ✅ Portfolio Best Practices
- Shows production experience without violating NDAs
- Demonstrates technical skills through descriptions
- Maintains professional credibility
- Respects client/company confidentiality

### ✅ Template Behavior
The portfolio template should:
- Show "Live Demo" button **only if** `project.live_url` exists and is not empty
- Show "GitHub" button **only if** `project.github_url` exists and is not empty
- Show "Production Project" or "Confidential" badge for company projects
- Display full project details, features, and tech stack regardless of links
